# 일본길찾기

일본 지하철·전철에서 "눈앞의 이 열차 타도 돼?" 를 카메라로 확인해 주는 앱.
KORA(한국길찾기)의 형제 앱이다. 판정 엔진은 `../TrainBoardKit` 을 함께 쓴다.

- 번들 ID: `com.leeo.japantransit`, 스토어 이름 `일본길찾기: 일본 지하철 안내`
- 첫 사용자: 일본에 가는 한국인. 그다음 대만·홍콩·중국 여행자

## 왜 따로 내는가

KORA 는 일본인이 한국에서 쓰는 앱이다. 사용자, 스토어 이름·키워드, 결제 구조가 정반대라 앱을 나눴다.
일본은 승강장 방향보다 열차 종류(各停·急行·快速)와 직통 운전 행선지가 처음 온 사람을 헷갈리게 한다.
경로 안내는 乗換案内·NAVITIME·Google 지도가 이미 잘 하므로, 이 앱은 현장 확인 하나에 집중한다.

## 프로젝트

`JapanTransit.xcodeproj` 는 `project.yml` 에서 만든다. 설정은 project.yml 에서 고친다.

```
xcodegen generate
```

버전·빌드번호는 `Config/Version.xcconfig` 한 곳에만 둔다.

## 지금 있는 것

- **도시 9곳, 노선 63개**: 일본의 지하철 사업자 10곳 노선 전부와 지하철이 이어 달리는 구간(사이타마 고속철도·도요 고속선·기타오사카 급행·긴테쓰 게이한나선). 도쿄(도쿄메트로·도에이·JR 야마노테·주오·소부·사이쿄, 린카이선, 유리카모메, 모노레일, 게이큐, 게이세이), 요코하마, 오사카(메트로 9개와 순환선), 교토, 고베, 나고야, 후쿠오카, 삿포로, 센다이. 경로는 도시 안에서만 잇는다.
- **역 찾기**: 한국어·일본어·영어·역 번호, 내 근처 역, **지도에서 고르기**.
- **가고 싶은 곳으로 찾기**: 관광지 187곳(`data/spots`). "빅사이트"를 찾으면 国際展示場(린카이선, 걸어서 7분)과 東京ビッグサイト(유리카모메)를 보여 주고 누르면 그 역을 고른다. 출구·도보 시간은 실제로 연 출처로 확인한 것만 넣었다.
- **경로**: 역 사이 거리로 시간을 셈하고, 추천과 환승 적은 길. 그대로 이어 달리는 열차(사이쿄선→린카이선, 오에도선)와 갈아타는 곳, 개찰구 밖 환승, 회사가 바뀌면 요금이 따로 붙는다는 것까지.
- **표지판 그대로**: 역 번호 마크, 남색 방면 표지판("上野・池袋方面"), 노선도 타임라인.
- **급행 주의**: 내 역을 지나치는 열차, 지정석 유료 열차, 주말에만 지나치는 역(주오선 쾌속), 중간에 갈라지는 열차(貝塚行, 関西空港行).
- **틀리기 쉬운 곳마다 그림** (`RouteGuides.swift`): 경로 화면이 탈 때 · 갈아탈 때 · 내릴 때 헷갈리는 곳을 그려 준다.
  - 행선지 지도: 같은 승강장에 오는 열차 가운데 탈 행선지와 타면 안 되는 행선지(도중에 갈라짐, 내 역 앞에서 끝남).
  - 정차역 도표: 열차 종류마다 서는 역을 점으로, 걸리는 시간과 함께.
  - 환승 그림: 이름이 다른 역으로 걷는 환승, 개찰구 밖 환승, 역이 떨어져 있을 때 거리(역 좌표가 150m 넘게 벌어질 때만 숫자를 낸다).
  - 출구 표지판: 내린 역 근처 관광지로 가는 출구(`data/spots` 에 출구가 있는 곳만).
  - 열차가 멈췄을 때: 전광판 글자 풀이와, 멈춘 노선을 빼고 다시 찾은 길. 밤 11시부터는 막차 안내.
- **카메라 확인**: 열차 앞이나 전광판을 비추면 타도 되는지.

## 배포

DeployBar 가 한다(`deploy.env`). 스토어 문구는 `APPSTORE.md`, 릴리즈 노트는 `RELEASE_NOTES.md`,
소개·지원·개인정보 페이지는 `python3 scripts/make_docs.py` 로 만드는 `docs/`(GitHub Pages).
스크린샷은 `docs/screenshots/raw/ko/` 원본으로 `scripts/make_marketing_screenshots.py`,
헤더·검색 결과 그림은 `scripts/make_creative_assets.py`.
