# 일본길찾기

일본 지하철·전철에서 "눈앞의 이 열차 타도 돼?" 를 카메라로 확인해 주는 앱.
KORA(한국길찾기)의 형제 앱이다. 판정 엔진은 `../TrainBoardKit` 을 함께 쓴다.

- 번들 ID: `com.leeo.japantransit` (스토어 이름은 아직 정하지 않았다)
- 첫 사용자: 일본에 가는 한국인. 그다음 대만·홍콩·중국 여행자

## 왜 따로 내는가

KORA 는 일본인이 한국에서 쓰는 앱이다. 사용자, 스토어 이름·키워드, 결제 구조가 정반대라 앱을 나눴다.
일본은 승강장 방향보다 열차 종류(各停·急行·快速)와 직통 운전 행선지가 처음 온 사람을 헷갈리게 한다.
경로 안내는 乗換案内·NAVITIME·Google 지도가 이미 잘 하므로, 이 앱은 현장 확인 하나에 집중한다.

## 프로젝트

`JapanTransit.xcodeproj` 는 `project.yml` 에서 만든다. 설정은 project.yml 에서 고친다.

```
xcodegen generate
```

버전·빌드번호는 `Config/Version.xcconfig` 한 곳에만 둔다.

## 지금 있는 것 (0.1.0)

- **길찾기**: 출발역·도착역을 한국어(신주쿠), 일본어(新宿·しんじゅく), 영어(Shinjuku), 역 번호(M08)로 찾는다.
  내 위치에서 가까운 역도 고를 수 있다. "추천"과 "환승 적게" 두 경로를 보여 준다.
- **경로 안내**: 노선마다 타는 역, 표지판에서 찾을 일본어 글자("上野・池袋方面"), 역 번호가 커지는 쪽인지,
  몇 정거장인지, 갈아타는 곳과 따라갈 글자("○○線 のりかえ"), 회사가 바뀌면 요금이 따로 붙는다는 것까지.
- **급행 주의**: 역을 건너뛰는 열차(快速·急行·エアポート快特)가 내 역에 서는지, 지정석 유료 열차(TH ライナー·ロマンスカー·S-TRAIN)인지.
- **카메라 확인**: 승강장에서 열차 앞이나 전광판을 비추면 타도 되는지(초록), 반대 방향이거나 내 역에 안 서는지(빨강).
  판정은 `../TrainBoardKit`. 다른 회사 노선으로 이어 달리는 열차의 행선지(中央林間行 등)도 알아본다.
- **노선**: 회사별 노선과 역 순서, 역마다 갈아탈 수 있는 노선.

## 노선 데이터

`data/lines/*.json` 이 원본이고 앱은 이 폴더를 그대로 번들에 넣는다. 노선 20개(도쿄메트로 9, 도에이 4, JR 야마노테선,
도쿄 모노레일, 게이큐 공항선·본선 일부와 지선 몇 개). 일본어 위키백과의 노선·역 문서를 1차 출처로 모았고,
파일마다 `sources` 와 확인하지 못한 점(`notes`)이 적혀 있다.

- 같은 이름의 역은 자동으로 환승역이 된다. 이름이 다른 환승역(浜松町 ↔ 大門 등)은 `data/transfers.json` 에 근거와 함께 적는다.
- `python3 scripts/check_lines.py --fix`: 표지판 부제 정리(押上〈スカイツリー前〉 → 押上), ヶ/ケ 표기 차이, 환승 후보(이름 다르고 300m 안) 찾기.
- 대江戸線은 "6" 자 운행이라 `loopBreak`(都庁前 을 지나면 열차를 바꾼다)와 `continuations`(그대로 이어 가는 방향)를 적어 둔다.
- 유료 지정석 열차는 `"paid": true`.
